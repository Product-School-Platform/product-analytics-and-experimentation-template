# FinWise — Product Analytics & Experimentation Certification project template

> Fork this repo (**Use this template** on GitHub). Replace this README with your own as you progress through the cohort. By the end of Module 6 this file is your **certification submission**.

You are building a complete **growth-and-experimentation strategy for FinWise**. Each module pushes a real deliverable into its folder. At the end you finalise this README into a single, board-ready strategy — the repo *is* the submission.

---

## How to use this template

1. Click **Use this template** on GitHub (or fork it).
2. Rename your copy (e.g. `finwise-strategy`).
3. Clone it locally.
4. In M1, open `01-bet/` and add your first deliverable. Commit + push.
5. Repeat per module. Each module's lab names the file you commit.
6. At the end of M6, finalise this README so a stranger could read it and understand your FinWise strategy.

> **Submission for certification:** the URL of this repo, within 7 days of your cohort ending.

| Module | Folder | The deliverable |

| **M3 — Retention & Engagement** | `03-mechanic/` | The Mechanic — gamification / engagement mechanic |

| **M6 — Pricing & Monetization** | `06-model/` | The Model — pricing & packaging recommendation |

## Conventions

- One folder per module; commit that module's deliverable as markdown.
- Keep this README current — it's the dashboard reviewers read first.
- Optional: there is a dedicated time at the end of Module 6 for volunteers to walk through their builds, decisions, and key insights and takeaways from the course experience.
